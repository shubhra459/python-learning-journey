# Python Learning Journey 🐍

A collection of Python code files documenting my learning journey.

This repository contains individual Python files covering concepts, methods, functions, and practical examples from Python, NumPy, and Pandas.

### About This Repository

I maintain separate Python files to demonstrate different concepts and understand how individual functions and methods work.

Files are numbered sequentially (e.g., `python1.py`, `python2.py`, `python3.py`).

### Topics Covered

- **Python:** Fundamentals, data types, strings, lists, tuples, sets, dictionaries, and more.
- **NumPy:** Arrays and numerical operations.
- **Pandas:** Series, DataFrames, and basic data manipulation.

### How to Explore

1. Open the relevant folder.
2. Browse the numbered Python files.
3. Open any file to explore its code.
4. Run the code to understand its functionality.

### Purpose

This is an ongoing collection of my coding practice, experiments, and learning progress.

Feel free to explore, learn, and use the examples!
